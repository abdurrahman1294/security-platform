# V3.28 — Temporal Attack-Path & Digital-Twin Reasoning

V3.28 adds temporal state modeling and a bounded digital-twin reasoning layer.
It compares state snapshots, tracks when a chain may have been valid, and
requires revalidation after meaningful environmental changes.

## Payload assurance boundary

The platform deliberately does **not** generate unrestricted weaponized
payloads. It provides a catalog and validation contract for low-impact proof
markers and fixed lab/testbed proofs. Consequential execution remains behind
scope, authorization, and approval gates.

This allows the engine to answer the important question — *can this weakness
be safely proven?* — without turning the reasoning layer into a general-purpose
payload weaponizer.
