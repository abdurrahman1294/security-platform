# V5.0 Capability Fusion Attributions

This release contains an original implementation informed by documented public
architecture and feature descriptions from:

- HexStrike AI (MIT License): MCP integration, tool-selection concepts,
  specialist-agent concepts, vulnerability intelligence, caching, process
  management, browser/API workflows and fault recovery.
- PentestGPT (MIT License): deterministic supervisor/executor concepts,
  durable canonical state, task leases, evidence provenance, retries,
  provider abstraction, coverage/convergence concerns and local-model support.

No source files from either project are copied into this release. The V5.0
implementation is independently written and retains this platform's existing
scope, authorization, evidence and registered-tool controls.

Reference:
- https://github.com/0x4m4/hexstrike-ai
- https://github.com/GreyDGL/PentestGPT
