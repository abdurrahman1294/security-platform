## Important technical boundary
GNSS satellites provide positioning signals; they do not provide a public mechanism for arbitrary remote device tracking. Device location can only be obtained through an authorized source/device ecosystem that reports it.

For supported ecosystems, the engine selects applicable legitimate recovery mechanisms. Offline and powered-off recovery remain device/vendor/configuration dependent. No SIM does not universally prevent offline finding, but the engine never claims support without evidence.

The framework does not implement covert tracking, carrier interception, IMSI interception, spyware, account bypass, credential theft, or unauthorized location access.
