# Controlled R4 — Version 1.8

R4 actions are high-impact/state-changing assessment activities. The platform does not ship unrestricted exploit payloads. An R4 action requires:

1. explicit engagement ROE permission for that exact action;
2. valid authorization and in-scope target state;
3. a single-use operator approval token bound to request, action and target;
4. an engagement-specific adapter for the approved procedure; and
5. auditable evidence and an emergency-stop path.

R5 actions such as destructive payloads, uncontrolled propagation, real data exfiltration, ransomware simulation, credential spraying at scale, unrestricted RCE and automatic bounty submission remain permanently denied.
