# Final Excellence Expansion — 1.5.0

- Added evidence-backed capability matrix spanning web, API, infrastructure, network, AD, AWS/cloud, OSINT, bug bounty and reporting.
- Added pentest depth tracking that separates implemented capability from executed/evidence-backed capability.
- Expanded PentestEngine with API, authenticated, AD, AWS read-only and finalization stages.
- Full pentest default now includes intelligence and final readiness/reporting.
- Updated specialist registry and platform schema to 1.5.
- Added tests for the new capability/depth layer.

## Important
A capability being listed does not mean a vulnerability was found or a domain was exhaustively tested. Tool availability, target technology, authorization, evidence and human review determine actual assessment coverage.
