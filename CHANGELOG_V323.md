# V3.23 — Universal Execution Graph

## Added
- Evidence-driven universal execution graph.
- Evidence artifact ingestion from existing JSON evidence directories.
- Cross-surface and cross-perspective coverage matrix.
- Candidate next-step scoring.
- Failure-aware alternative hypotheses.
- Resumable graph advancement API.
- Governance metadata carried into every graph.
- `fabric --action execution-graph` CLI path.
- `SecurityPlatform.universal_execution_graph()` API.

## Safety boundary
V3.23 is orchestration/planning, not an unrestricted exploit executor. It preserves V3.22 R4 exact-action approval/ROE/scope controls and the hard-denied R5 classes.
