# V4.0 Autonomous Offensive Security Intelligence Platform

V4.0 unifies the mature governed layers into one mission intelligence fabric:

- persistent competing hypotheses
- explicit prerequisite/dependency state
- highest-value next tests
- bounded hypothesis-to-exploitation planning
- adaptive specialist priorities
- attack-chain planning with verification gates
- evidence inventory and provenance-aware metrics
- coverage gaps
- mission fingerprints and learning-memory policy
- operator readiness and blocked-dependency decisions

## Truth model

Execution success is not security evidence. Evidence is not automatically corroboration. A hypothesis is never a finding without verified evidence.

## Governance

Authorization, scope, approval gates and registered engine entry points remain authoritative. V4.0 does not add arbitrary shell execution, scope expansion, persistence, credential theft, covert C2, destructive operations, or unrestricted payload generation.
