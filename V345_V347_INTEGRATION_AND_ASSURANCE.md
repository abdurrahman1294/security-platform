# V3.45–V3.47 Integration and Assurance

Run the complete campaign with:

```bash
python tools/run_complete_test_campaign.py
```

It runs compilation, the regression suite, the capability-contract lab, self-security, realistic vulnerability fixtures, the multi-domain integration range, campaign-quality scoring, and deterministic resilience checks.

The integration range uses local fixtures and synthetic markers. Results measure the platform's fixture integration contracts and must not be interpreted as universal vulnerability-detection accuracy.
