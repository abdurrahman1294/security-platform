# V3.23 Universal Execution Graph

V3.23 turns the V3.22 universal specialist router into an evidence-driven planning layer.

## Capabilities
- Evidence graph with secret-field redaction.
- 35-surface × multi-perspective coverage matrix.
- Dynamic next-step scoring using evidence relevance, novelty, specialist availability, and perspective value.
- Failure-aware alternative hypotheses using perspective shifts and test substitution.
- Resumable state advancement from observed results.
- Explicit governance metadata on every graph: authorization, scope recheck, approval, no scope expansion, and denied autonomy classes.
- Specialist routing remains separate from execution authority.

## Boundary
The graph is an orchestrator/planner. It does not add unrestricted RCE, credential theft, persistence deployment, stealth/evasion, propagation, real exfiltration, destructive actions, or carrier bypass. Existing V3.22 R4 controlled procedures remain governed by their exact ROE, approval, scope, and registered lab/specialist adapter contracts.

## Output
`evidence/universal-evidence-graph-v323.json` and `evidence/universal-execution-graph-v323.json`.
