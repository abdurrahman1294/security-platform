# Security Platform V3.8

V3.8 is the intelligence-fabric depth release. It connects asset context, multi-hop dependency hypotheses, finding confidence, provenance, remediation dependencies, authenticated session modeling, plugin contracts, and coverage into a deterministic evidence-driven loop.

Use `securityctl intelligence` to build the V3.8 intelligence artifacts for an existing engagement output directory.

The platform remains scope-controlled and evidence-driven. Planning and correlation never confer authorization and do not replace operator validation.
